INSTALL

아이폰 홈 화면에 설치

  1. Safari에서 ESCAPE PASS 주소를 엽니다.
  2. 하단의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 추가 후 홈 화면의 ESCAPE PASS 아이콘으로 실행합니다.

PWA 설치는 HTTPS 주소에서 사용하는 것이 가장 안정적입니다.
